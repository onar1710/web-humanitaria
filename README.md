# Misión Humanitaria - Sitio Web Oficial

Sitio web oficial de Misión Humanitaria, una organización comprometida con brindar servicios integrales de salud visual, odontológica, asesoría legal y contable a comunidades vulnerables y empresas en Colombia.

## 🌟 Características

- **Diseño Moderno**: Interfaz con estilo neon verde y efectos visuales atractivos
- **Responsive**: Diseño adaptativo para móviles, tablets y escritorio
- **Secciones Informativas**:
  - Banner promocional
  - Carrusel de servicios
  - Menú de categorías
  - Sección de estrategia comercial
  - Quiénes somos (Misión, Visión, Valores)
  - Actividades recientes
  - Formulario de contacto
- **Botón Flotante de WhatsApp**: Contacto directo con la organización
- **Animaciones**: Efectos de desplazamiento y transiciones suaves
- **Optimizado**: Rendimiento optimizado con Astro

## 🛠️ Tecnologías Utilizadas

- **Astro**: Framework para sitios web estáticos
- **Tailwind CSS**: Framework de utilidades CSS
- **TypeScript**: Tipado estático para mayor seguridad
- **HTML5**: Estructura semántica
- **CSS3**: Estilos y animaciones

## 🚀 Comandos

Todos los comandos se ejecutan desde la raíz del proyecto:

| Comando | Acción |
| :--- | :--- |
| `npm install` | Instala las dependencias |
| `npm run dev` | Inicia el servidor de desarrollo en `localhost:4321` |
| `npm run build` | Construye el sitio para producción en `./dist/` |
| `npm run preview` | Previsualiza la construcción localmente |
| `npm run astro ...` | Ejecuta comandos CLI de Astro |

## 📱 Secciones del Sitio

- Barra amarilla con servicios en scroll
- Navegación principal con logo
- Barra de búsqueda

### Secciones Principales
- **Banner Verde**: Promociones destacadas
